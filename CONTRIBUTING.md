# Contributing to ffd

Welcome, and thanks for contributing to ffd!

## How to Contribute

1. Fork the repository.
2. Clone your fork and make your changes.
3. Push your changes to your fork.
4. Open a Pull Request.

Before contributing, please understand the project structure and how its components work. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Using AI

You may use AI tools while contributing, but you are responsible for the code you submit.

Before opening a Pull Request:

* Review AI-generated code.
* Understand what the code does.
* Test it yourself.
* Make sure it fits the project's structure and style.

Please do not submit unreviewed or untested AI-generated code.
